## Sobre o projeto

**Crônicas de Mandacaru** é um jogo educacional desenvolvido com foco em acessibilidade e inclusão para pessoas com Transtorno do Espectro Autista (TEA). Ambientado no sertão nordestino, o projeto utiliza uma abordagem lúdica, visual e interativa para ensinar conceitos de lógica de programação integrados à linguagem Python, proporcionando uma experiência adaptada às necessidades e diferentes formas de aprendizagem dos usuários.


### Objetivos

- 🧩 Tornar o aprendizado de programação acessível para pessoas com TEA
- 🌵 Valorizar a cultura nordestina por meio da narrativa e estética do jogo
- 🐍 Introduzir conceitos de lógica e Python de forma gradual e intuitiva

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/cronicasdemandacarudev-bit/cronicasdemandacaru-dev-ppom.git
   ```
2. Abra o **Godot Engine 4.5**
3. Clique em **Import** e selecione a pasta `cronicas-de-mandacaru-ppom/`
4. Aguarde o Godot importar os assets
5. Pressione **F5** para iniciar o jogo
